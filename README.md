# 🕹️ Game Station Hub — Arcade HTML5

Plataforma interactiva estilo *Arcade Hub* desarrollada con tecnologías web nativas (**HTML5, CSS3 y JavaScript Vanilla**). Centraliza una colección de minijuegos independientes en una interfaz moderna con efectos de cristal (*glassmorphism*), previews dinámicas y un reproductor in-app.

---

## 🚀 Demo en Vivo
Puedes probar la plataforma y jugar directamente aquí:  
👉 **[Ver Demo en Render](https://sala-de-juegos-jjvg.onrender.com)** 

---

## 🎮 Juegos Incluidos

1. **🧾 Caja Registradora:** Simulador interactivo de gestión de tienda, cobros y cálculo de cambio.
2. **🏎️ Carreras de Autos:** Minijuego de reflejos y velocidad con esquiva de obstáculos en pista.
3. **🥊 Juego de Peleas:** Combate arcade 1v1 con mecánicas de daño, barras de vida y combos.
4. **🎰 Tragaperras (Slots):** Juego de azar y simulación de tragamonedas clásica con acumulación de créditos.

---

## ✨ Características Principales

- **Reproductor Modal Integrado:** Ejecuta cada juego sin salir de la página principal, con soporte para modo pantalla completa (`Fullscreen API`) y cierre rápido con tecla `ESC`.
- **Vista Previa en Vivo:** Tarjetas con vista en miniatura de cada juego.
- **Buscador y Filtro en Tiempo Real:** Búsqueda instantánea de juegos por título y palabras clave.
- **Diseño Moderno & Responsivo:** Estética oscura gamer, sombras de neón, gradientes sutiles y compatibilidad con pantallas de escritorio y móviles.
- **Cero Dependencias:** Construido 100% en Vanilla JS, sin frameworks pesados ni dependencias externas.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica e incrustación mediante iframes.
- **CSS3:** Flexbox, CSS Grid, Glassmorphism, animaciones y CSS Variables.
- **JavaScript (ES6+):** Manipulación dinámica del DOM, eventos de teclado y filtros en tiempo real.
- **Despliegue:** Render (Static Site).
